# Signalman

A country flag guessing game. Spin the wheel, name the flag it lands on.

## Playing

The carousel idles with a slow spin. **Spin** accelerates it and lands on one flag, which
expands so you can name it. Guesses come from the autocomplete, so spelling is never the
problem. A correct guess retires the flag from the pool; **Skip** puts it back on the wheel
and **Give Up** reveals the answer and retires it. **Reset** refills the pool with all 255
flags.

Progress lives in local storage, so closing the tab keeps your pool.

## Development

```
pnpm install
pnpm run dev
```

| Script                    | What it does                                    |
| ------------------------- | ----------------------------------------------- |
| `pnpm run dev`            | Vite dev server                                 |
| `pnpm run build`          | Type-check and build to `dist`                  |
| `pnpm run lint`           | oxlint                                          |
| `pnpm run format`         | oxfmt                                           |
| `pnpm run types:check`    | TypeScript only                                 |
| `pnpm run flags:generate` | Re-vendor flag SVGs and regenerate country data |

## Flag data

`public/flags` and `src/data/countries.ts` are generated by `scripts/generate-flags.mjs`
from the `flag-icons` package: every two-letter code CLDR can name, which is the 249
officially assigned ISO 3166-1 alpha-2 codes plus six reserved ones (European Union,
United Nations, Kosovo, Canary Islands, Clipperton Island, Diego Garcia). Country names come from CLDR via `Intl.DisplayNames`, with overrides and search
aliases defined in the script. Edit the script, not the generated files.

## Deployment

Netlify builds from `netlify.toml` and publishes `dist`.
