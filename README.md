# Signalman

A country flag guessing game. Spin the wheel, name the flag it lands on.

## Playing

The carousel idles with a slow spin. **Spin** accelerates it and lands on one flag, which
expands so you can name it. Guesses come from the autocomplete, so spelling is never the
problem. A correct guess retires the flag from the pool; **Skip** puts it back on the wheel
and **Give Up** reveals the answer and retires it.

## Study Mode

The menu offers **New Game** and **New Study Session**. Study Mode drills a growing set
instead of the whole pool, and skips the carousel entirely — flags come one after another.

A session opens with five random flags, each needing three correct guesses. Clear them all
and five more are added, every count resets, and the round repeats: the five new flags need
three correct guesses, everything introduced earlier needs one. A wrong guess or a **Give
Up** wipes that flag's count back to zero, so a flag is only learned once you can name it
cleanly. Rounds continue until all 242 flags have been through the rotation.

Only one session exists at a time. The mode you are in is remembered, so a reload drops you
back where you were — but starting a new game clears a study session and vice versa.

## Development

```
pnpm install
pnpm run dev
```

| Script                    | What it does                                    |
| ------------------------- | ----------------------------------------------- |
| `pnpm run dev`            | Vite dev server                                 |
| `pnpm run build`          | Type-check and build to `dist`                  |
| `pnpm run lint`           | oxlint                                          |
| `pnpm run format`         | oxfmt                                           |
| `pnpm run types:check`    | TypeScript only                                 |
| `pnpm run flags:generate` | Re-vendor flag SVGs and regenerate country data |

## Flag data

`public/flags` and `src/data/countries.ts` are generated by `scripts/generate-flags.mjs`
from the `flag-icons` package. The pool is every two-letter code CLDR can name — the 249
officially assigned ISO 3166-1 alpha-2 codes plus four reserved ones (European Union,
United Nations, Kosovo, Canary Islands) — minus thirteen codes whose flag art is identical
to another entry's and so cannot be told apart in play. That leaves 242.

The duplicates are listed in `DUPLICATE_FLAGS` in the script, each paired with the code
that keeps the flag: nine territories flying the plain French tricolour, plus Heard &
McDonald Islands (Australia), Saint Helena (United Kingdom), US Minor Outlying Islands
(United States) and Diego Garcia (British Indian Ocean Territory).

Country names come from CLDR via `Intl.DisplayNames`, with overrides and search aliases
defined in the script. Edit the script, not the generated files.
